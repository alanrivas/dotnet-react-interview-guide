# Guía de Entrevistas Full Stack .NET + React

Preparación completa para entrevistas técnicas desde Junior hasta Senior, cubriendo .NET/C#, React, SQL, arquitectura y más.

**Sitio:** https://dotnet-react-interview-guide.alanrivas.me

## Contenido

| Nivel | Documentos | Temas principales |
|-------|-----------|-------------------|
| 🟢 Junior | 20 | C#, .NET, React, SQL básico, HTML/CSS |
| 🟡 Semi-Senior | 27 | Patrones de diseño, EF Core, TypeScript, Testing, JWT |
| 🔴 Senior | 48 | Arquitectura, Microservicios, DDD, CQRS, Performance, Seguridad |

## Instalación

```bash
npm install
```

## Desarrollo local

```bash
npm start
```

Abre http://localhost:3000 con recarga automática en cambios.

## Build

```bash
npm run build
```

Genera los archivos estáticos en `build/`. El build falla si hay links rotos.

## Deploy

El sitio se despliega automáticamente a GitHub Pages cuando se hace push a `main`, via GitHub Actions.
